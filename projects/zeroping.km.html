បញ្ហា

PHP framework "ស្រាល" ភាគច្រើន នៅតែទាញយក ORM, container ឬ router ពីភាគីទីបី ដូច្នេះអ្នកទទួលបានកញ្ចប់ជាច្រើនដែលអ្នកមិនបានជ្រើសរើស ហើយពិបាកអាន។

ZeroPing ចង់បង្ហាញថា framework ពេញលេញ និងងាយស្គាល់ អាចបង្កើតបានពីមូលដ្ឋានគ្រឹះ — អានបានពីដើមដល់ចប់ គ្មានអ្វីលាក់ក្នុង vendor — ហើយដើម្បីយល់ឱ្យស៊ីជម្រៅពីរបៀបដែល framework ដូចជា Laravel ដំណើរការ តាមរយៈការបង្កើតវាផ្ទាល់។

Routing

Active Record ORM

សុវត្ថិភាព

Queue និង scheduler
